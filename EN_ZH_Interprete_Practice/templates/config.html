安装说明

本地 Whisper（推荐）

pip install openai-whisper

本地运行，无需 API Key，完全免费，支持 99 种语言

视频处理（FFmpeg）

# Windows: 下载 https://ffmpeg.org/download.html
# Mac: brew install ffmpeg
# Linux: sudo apt install ffmpeg

功能说明

  • 自动检测语言: Whisper 会自动识别音频语言，准确率高
  • 手动指定语言: 如果自动检测错误，可手动选择正确的语言
  • 多语言混合: 建议选择主要语言或使用自动检测
  • 所有数据仅存储在本地 data 目录
